# Prototype LFBB — importation jeunesse 2025–2026

Branche isolée du site live BC-Seraing-Live. Les quatre URLs du premier lot (K2 D, Waremme D, Waremme C, Attert D) sont répertoriées dans le manifeste.

**Règle Attert** : les tableaux D restent éligibles ; les tableaux C sont amicaux et ne doivent être ni importés ni comptabilisés. Les changements officiels restent soumis à validation humaine.

Barème D → C en vigueur depuis le 1er août 2025 : 4 à 7 joueurs = vainqueur 2 / finaliste 1 ; 8 à 11 = 4 / 2 ; 12 et plus = 6 / 3. Montée proposée à 6 points cumulés dans une catégorie d'âge.

Source : https://lfbb.be/criteres-montee-d-c-tournois-jeunes-lfbb/

Le prototype exécutable testé (9 tests locaux réussis) est pour l'instant livré dans l'archive ZIP de la conversation. La copie des modules sur cette branche reste à intégrer et à tester sur un environnement avec accès réseau TS.
